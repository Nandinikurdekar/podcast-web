# 🎧 Podcast Web App

A modern podcast streaming UI built using React and Tailwind CSS.

## Features
- Play podcasts 🎵
- Mini expandable player
- Favorites system ❤️
- Search functionality 🔍
- Smooth animations ✨

## Tech Stack
- React
- Tailwind CSS
- Framer Motion

## How to run
npm install
npm start
